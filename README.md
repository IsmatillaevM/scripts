# WinPE Backup

Автономный скрипт для резервного копирования пользовательского профиля Windows из среды WinPE (Windows Preinstallation Environment) или обычной Windows. Один `.cmd` файл, никаких зависимостей, работает в самом ограниченном окружении.

Создан для ситуаций, когда Windows не грузится, но данные пользователя нужно спасти перед переустановкой системы.

## Для кого этот скрипт

- **Системные администраторы** — быстро снять данные перед переустановкой Windows
- **IT-поддержка** — автоматизировать перенос профиля на новое железо
- **Сервисные инженеры** — спасти данные с умирающего диска
- **Обычные пользователи** — сделать полный бэкап перед обновлением системы

Скрипт работает даже когда Windows не грузится — достаточно загрузиться с WinPE-флешки и запустить одну команду.

## Что он делает

За один запуск скрипт:

1. **Находит** съёмный диск для сохранения бэкапа (без `diskpart`)
2. **Находит** пользовательский профиль на системном диске
3. **Копирует** все основные папки (Documents, Desktop, Pictures, Videos, Music, Downloads)
4. **Экспортирует** AppData\Roaming и AppData\Local (с чисткой кэшей)
5. **Извлекает** закладки браузеров (Chrome, Edge, Firefox)
6. **Собирает** Outlook-архивы (`.pst`, `.ost`)
7. **Сохраняет** RDP-подключения, SSH-ключи, PuTTY-сессии
8. **Копирует** пользовательские шрифты и стикеры Sticky Notes
9. **Извлекает** Wi-Fi профили с паролями в открытом виде
10. **Выгружает** список установленных программ из реестра
11. **Экспортирует** драйверы системы (DISM)
12. **Сохраняет** OEM-ключ Windows из BIOS
13. **Собирает** информацию о железе (CPU, RAM, GPU, диски, BIOS)
14. **Экспортирует** планировщик задач (XML + CSV)
15. **Сохраняет** список сертификатов пользователя
16. **Копирует** файл `hosts`
17. **Генерирует** HTML-отчёт с визуализацией содержимого
18. **Опционально** проверяет хеши и сжимает всё в ZIP

Результат — одна папка на флешке со всем, что было у пользователя, плюс всё что нужно для восстановления на новой системе.

## Быстрый старт

### Вариант 1: Из загруженной Windows

1. Скачай `winpe-backup.cmd` на флешку
2. Правый клик → **Запуск от имени администратора**
3. Отвечай на вопросы (режим, verify, zip)
4. Жди завершения

### Вариант 2: Из WinPE (когда Windows не грузится)

1. Запиши WinPE на флешку (через **Rufus**, **Ventoy** или **Win10XPE**)
2. Положи `winpe-backup.cmd` рядом с WinPE-образом или в корень флешки
3. Загрузись с флешки (в BIOS выбери её как Boot Device)
4. Открой командную строку (`Shift+F10`)
5. Запусти:
   ```cmd
   E:\winpe-backup.cmd
   ```
   (где `E:` — буква твоей флешки; скрипт сам найдёт назначение, даже если буква другая)

## Как это работает

### Автопоиск дисков без `diskpart`

Скрипт использует трёхуровневый fallback для обнаружения дисков:

1. **`wmic logicaldisk`** — работает в большинстве версий WinPE
2. **PowerShell `Get-PSDrive`** — для новых сборок Windows 11 PE, где убрали `wmic`
3. **`fsutil` + перебор букв A–Z** — последний резерв, работает всегда

Какой метод сработал — выводится на экран (`[i] Drive detection method: ...`).

### Как отличается источник от назначения

- **Назначение** (куда копировать) — диск, на котором **нет** `\Windows\System32\` и это не `X:` (RAM-диск WinPE)
- **Источник** (откуда копировать) — диск, на котором есть `\Users\<имя>\Desktop`
- Если найдено несколько — скрипт покажет пронумерованный список с метками и свободным местом

### Умное копирование

Для копирования используется **`robocopy`** с настройками:
- `/E` — все подпапки, включая пустые
- `/R:1 /W:1` — одна попытка повтора, одна секунда ожидания (не висеть на битых файлах)
- `/MT:16` — 16 потоков параллельно
- `/XJ` — пропуск junction-точек (защита от бесконечных циклов)
- `/TEE` — вывод в консоль и в лог одновременно
- Исключение кэшей, временных файлов, системного мусора

## Режимы работы

При запуске скрипт спросит режим:

### 1. Full (полный бэкап)
Копирует всё с нуля в новую папку `Backup_<имя>_YYYYMMDD_HHMM`. Безопасный выбор по умолчанию.

### 2. Incremental (инкрементальный)
Находит последнюю папку бэкапа этого же пользователя и **добавляет** только изменённые файлы (`robocopy /XO`). Экономит время при регулярных бэкапах.

### 3. Mirror (зеркало)
Делает папку назначения **точной копией** источника (`robocopy /MIR`). **Удаляет** файлы на флешке, которых больше нет в источнике. Используй осторожно.

### Дополнительные опции

**Verify (проверка хешей)** — после копирования сверяет SHA256 файлов в папке `Documents`. Пишет результат в `_verify.log`.

**ZIP (сжатие)** — упаковывает всю папку бэкапа в `.zip`. Использует `tar` (Windows 10+) или PowerShell `Compress-Archive`.

## Что копируется

### Основные папки профиля
Desktop, Documents, Pictures, Videos, Music, Favorites, Links

### Загрузки (специальная обработка)
Копируется всё, **кроме** установщиков: `.exe`, `.msi`, `.msix`, `.appx`, `.iso`, `.img`, `.vhd`, `.vhdx`, `.dmg`, `.pkg`, `.deb`, `.rpm`

### AppData
Копируется, но исключаются:
- Все браузерные кэши (`Cache`, `GPUCache`, `ShaderCache`, `Service Worker`, `IndexedDB` и т.д.)
- Логи и крэш-дампы (`Crashpad`, `CrashDumps`, `logs`, `Logs`)
- Временные файлы (`Temp`, `tmp`)
- Пакетные менеджеры (`node_modules`, `__pycache__`, `.venv`, `pip-cache`, `pnpm-cache`, `yarn-cache`)
- Системные пакеты (`Packages`, `PackageStaging`, `SquirrelTemp`)
- Браузерные истории и cookies
- Драйверные кэши (`NVIDIA`, `AMD`, `Intel`)

### Специальные данные
- **Outlook**: `.pst`, `.ost`, `.nst` из `Documents\Outlook Files` и из AppData
- **RDP**: все `.rdp` файлы из Documents + Remote Desktop app
- **SSH**: вся папка `.ssh` + PuTTY-сессии из реестра пользователя
- **Шрифты**: пользовательские шрифты из `AppData\Local\Microsoft\Windows\Fonts`
- **Sticky Notes**: современные (Store) и устаревшие

### Системная информация
- **Установленные программы** — из реестра (не `wmic product`, который медленный и опасный)
- **Wi-Fi пароли** — через `netsh wlan export profile key=clear`; в WinPE — зашифрованные XML
- **Windows ключ** — OEM из BIOS через `wmic path softwarelicensingservice`
- **Драйверы** — через `DISM /export-driver` (готовы для `pnputil` после переустановки)
- **Железо** — через `wmic cpu/memorychip/baseboard/bios`
- **Планировщик задач** — каждая задача отдельным XML
- **Сертификаты** — список через `certutil -store`

## Что НЕ копируется (специально)

- **Файлы установщиков** в Downloads (чтобы не раздувать бэкап)
- **Кэши браузеров** (миллионы мелких файлов, которые пересоздаются сами)
- **Node modules, pip cache, Docker images** (легко восстановить)
- **Папка Public** (не относится к конкретному пользователю)
- **Служебные профили** (`Default`, `Public`, `defaultuser0`, `WDAGUtilityAccount`)
- **Файлы системного мусора**: `Thumbs.db`, `desktop.ini`, `*.tmp`, `*.log1`, `*.etl`
- **Корзина** (`$Recycle.Bin`) и `System Volume Information`

Если нужно скопировать что-то из исключённого — отредактируй список `/XD` / `/XF` в соответствующей функции.

## HTML-отчёт

После завершения в корне бэкапа появится `report.html` — автономная страница с:

- **Метаданные** — пользователь, источник, назначение, дата, общий размер
- **Карточки по категориям файлов** — Documents, Images, Videos, Audio, Archives, Code, Executables; каждая с количеством файлов и пропорциональной полоской
- **Top 20 самых больших файлов** — таблица с размерами в MB
- **Список папок бэкапа** — что было скопировано
- **QR-код** — со сводкой (можно отсканировать телефоном)

Страница **полностью автономная**, работает без интернета, тёмная тема, адаптивная вёрстка. Открывается в любом браузере с флешки двойным кликом.

## Восстановление из бэкапа

После переустановки Windows или на новом компьютере:

### Пользовательские файлы
Просто скопируй папки Desktop / Documents / Pictures и т.д. обратно в `C:\Users\<имя>\`.

### Закладки браузеров
- **Chrome**: положи файл `Bookmarks` в `%LOCALAPPDATA%\Google\Chrome\User Data\Default\`
- **Edge**: аналогично в `%LOCALAPPDATA%\Microsoft\Edge\User Data\Default\`
- **Firefox**: скопируй папку профиля в `%APPDATA%\Mozilla\Firefox\Profiles\`

### Outlook
Скопируй `.pst` файлы в любое удобное место и подключи через Outlook: **File → Open & Export → Open Outlook Data File**.

### Wi-Fi
```cmd
netsh wlan add profile filename="E:\...\WiFi\SSID.xml"
```

### Драйверы
```cmd
pnputil /add-driver E:\...\_SystemInfo\Drivers\*.inf /subdirs /install
```

### Запланированные задачи
```cmd
schtasks /create /tn "Имя" /xml "E:\...\ScheduledTasks\имя.xml"
```

### PuTTY сессии
Двойной клик по `putty_sessions.reg` — импортирует в реестр.

### Шрифты
Выдели всё в `_UserFonts\` → правый клик → **Установить**.

### Hosts
Скопируй `_SystemInfo\hosts` в `C:\Windows\System32\drivers\etc\hosts` (нужны права админа).

## Требования

### Минимальные
- **Windows 7** и новее, или **любой WinPE**
- Доступ к командной строке
- Флешка/внешний диск с достаточным местом (скрипт покажет оценку)

### Для полной функциональности
- **Права администратора** (без них часть AppData пропустится)
- **`robocopy`** (есть во всех Windows с Vista)
- **`certutil`** — для verify (есть в Win 7+)
- **`DISM`** — для экспорта драйверов (есть в Win 7+)
- **`tar`** или PowerShell — для создания ZIP (Win 10+)
- **Интернет** — только для QR-кода (не обязательно)

### Что опционально
- `wmic` — если нет, скрипт переключится на PowerShell / fsutil
- PowerShell — fallback вариант, если нет wmic
- Соединение с сетью — только для скачивания PNG с QR-кодом

## Решение проблем

### «Не вижу русских букв / кракозябры»
Скрипт специально написан на английском, т.к. в WinPE часто **нет шрифта с кириллицей**. Все сообщения в консоли и логах — на латинице. Это сделано намеренно и исправления не требует.

### «Flash диск не определяется»
Проверь:
1. Что флешка подключена **до** запуска скрипта
2. Что она не является `X:` (это RAM-диск WinPE)
3. Что на ней нет папки `\Windows\System32\` (иначе скрипт считает её системной)
4. Что в WinPE загрузился драйвер USB (в некоторых минимальных сборках его нет)

Если `[i] Drives found:` показывает только `X:`, значит флешка не видна системе — попробуй другой USB-порт или другой WinPE-образ.

### «wmic не работает в моём WinPE»
Это нормально для новых сборок Windows 11 PE — Microsoft убрал `wmic`. Скрипт автоматически переключится на PowerShell или `fsutil`. Проверь строку:
```
[i] Drive detection method: fsutil
```

### «Копирование висит на каком-то файле»
Файл заблокирован или битый. `/R:1 /W:1` ждёт только 1 секунду и пропускает. Если висит дольше — проверь `_backup.log`, там будет имя проблемного файла. Можно нажать `Ctrl+C` и запустить снова в режиме `Incremental` — продолжит с места.

### «Verify говорит MISMATCH»
Возможные причины:
- Файл изменился между копированием и проверкой (норма для AppData)
- Битый сектор на источнике — файл скопировался, но прочитался иначе
- Повреждена флешка — проверь её через `chkdsk`

### «ZIP не создаётся»
Нужен `tar` (Win 10+) или PowerShell. В WinPE обычно есть PowerShell. Если нет — пропусти этот шаг, можешь сжать на другом компьютере позже.

### «Запрашивает пароль / требует UAC»
Запусти от администратора. В WinPE все процессы и так админские, но в обычной Windows — правый клик → **Запуск от имени администратора**.

### «Не находит профиль пользователя»
Проверь что в `C:\Users\` есть папка с именем пользователя и внутри неё — `Desktop`. Если Windows была повреждена, профиль может отсутствовать. Проверь другие диски: иногда Windows ставится не на C:.

## FAQ

**В: Сколько времени занимает бэкап?**
О: Зависит от размера. На USB 3.0 примерно 1 ГБ за 10–30 секунд. 100 ГБ — около 30–60 минут. Verify удваивает время. ZIP добавляет ещё столько же.

**В: Можно ли прервать и продолжить?**
О: Да. Нажми `Ctrl+C`, потом запусти снова в режиме **Incremental** — скрипт продолжит с того места, где остановился.

**В: Удалит ли скрипт что-то с моего диска?**
О: **Нет**, кроме режима **Mirror**, который удаляет файлы с флешки, если их нет в источнике. Источник никогда не изменяется.

**В: Будет ли работать на Windows XP?**
О: Нет. Нужен как минимум Vista/Win 7 (из-за robocopy с нужными флагами).

**В: Можно ли копировать между сетевыми дисками?**
О: Да, если буква диска назначена через `net use`. Скрипт их увидит.

**В: Что делать, если флешка меньше профиля?**
О: Скрипт предупредит. Варианты:
- Использовать больший диск
- Исключить тяжёлые папки (Videos, Downloads) — закомментировать строки `call :sect ...`
- Разбить на несколько запусков с разными папками

**В: Как сделать бэкап нескольких пользователей?**
О: Запусти скрипт отдельно для каждого — он спросит кого выбрать. Каждый бэкап пойдёт в свою папку `Backup_<имя>_<дата>`.

**В: Копируется ли зашифрованный BitLocker диск?**
О: Да, если он разблокирован в текущей сессии WinPE. Если нет — сначала разблокируй: `manage-bde -unlock C: -password`.

**В: Как часто можно делать бэкапы?**
О: Хоть каждый день — используй режим **Incremental**, он копирует только изменения.

## Безопасность и приватность

**ВНИМАНИЕ**: бэкап содержит **чувствительные данные**:

- **Пароли Wi-Fi в открытом виде** (`_wifi_passwords.txt`)
- **SSH-ключи** (`_SSH\`) — доступ к твоим серверам
- **OEM-ключ Windows** (`windows_product_key.txt`)
- **Куки и токены** браузеров внутри AppData
- **Outlook `.pst`** может содержать всю почту
- **PuTTY-сессии** могут содержать сохранённые пароли

**Рекомендации:**
1. Храни флешку физически в безопасном месте
2. Если бэкап уходит кому-то — зашифруй его (например VeraCrypt-контейнером)
3. Используй режим **ZIP** + зашифрованный архив через 7-Zip с паролем
4. После восстановления **удали** бэкап с флешки через безопасное удаление

---

## Ограничения

- **DPAPI-зашифрованные данные** (пароли браузеров, Credential Manager) **не расшифровываются** в WinPE — для этого нужна оригинальная учётка пользователя
- **Шифрованные EFS файлы** будут скопированы как есть, но без ключа ты их не прочитаешь
- **BitLocker-диски** должны быть разблокированы до запуска
- **OneDrive placeholders** могут не скачать реальное содержимое — проверь, что все файлы «доступны локально»
- **Длинные пути** (>260 символов) могут обрезаться — robocopy с ними справляется, но Windows потом может не видеть
- **Файлы в использовании** (например открытый Outlook `.ost`) могут пропуститься — в WinPE этой проблемы нет
